# FFT 模擬專案
此專案主要上傳 256-point-FFT 電路設計的 MATLAB 和 Verilog 模擬檔案。

## 專案架構

```text
FFT_matlab_source_code/
FFT_verilog_source_code/
FFT_reference.pdf
```

## 內容說明

- `FFT_matlab_source_code/`  
  放置 FFT 的 MATLAB source code，主要用於演算法定點數模擬與驗證。

- `FFT_verilog_source_code/`  
  放置 FFT 的 Verilog source code，主要用於硬體設計與模擬。

- `FFT_reference.pdf`  
  本設計所參考的書籍。
